DualStream v2

Dual playback • Playlists • YouTube • Spotify
LOCAL FIRST
For iPhone: use audio files and tap Play both.
Important: iOS simultaneous audio uses one Web Audio mixer for uploaded audio tracks. Large files require decoding in memory. YouTube and Spotify are official embedded players and may not synchronize with other players due to platform and browser policies. YouTube embeds need an HTTPS website origin—opening this HTML as a local file may trigger YouTube error 153. Host the folder on a free static host. Some YouTube videos disable embedding. Spotify may play previews depending on account/browser. Download is available for your own files and direct media URLs where permitted; this app does not extract protected streams.
Free hosting: Upload this folder to GitHub Pages or Cloudflare Pages. The URL must start with https://, not file://. For direct URLs, playback/download also depends on remote server permissions.
